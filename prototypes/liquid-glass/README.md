# 液态玻璃材质小样

独立、无依赖的浏览器原型，用于先评审材质。未接入 Flutter 页面，不读写账号或预约数据。

用支持 WebGL 的浏览器打开 `index.html` 即可。拖动玻璃或用方向键移动；可暂停背景、切换折射、调节折射及轻微模糊的强度，切换网格背景。

背景由 Canvas 2D 绘制，同一帧上传为 WebGL 纹理。圆角矩形的距离场确定边缘方向，弧面厚度梯度生成表面法线，`refract` 计算背景纹理的局部采样偏移。中心轻微放大，九点核对透过玻璃的背景做轻度柔化（默认约一个 CSS 像素，滑杆归零可完全关闭），细窄边缘使用同一表面法线产生清晰高光，前景文字不参与模糊。它是屏幕空间光学近似，不是原生 iOS 材质或完整光线追踪。

材质评审建议：暂停背景，切换“折射”查看同一处字形；在网格背景上拖动，观察边缘弯折是否跟随玻璃。无 WebGL 时显示错误，不使用渐变卡片冒充折射。

App 的原生实现位于 `lib/design/refractive_glass.dart` 和 `shaders/liquid_glass.frag`，通过 Impeller 的 `ImageFilter.shader` 直接采样实时背景，不需要逐帧截图。卡片位置在图层合成时更新，以覆盖保留图层的列表滚动；渲染器不支持或祖先离屏图层使坐标无法确定时使用轻微模糊回退。玻璃内部文字后绘制，嵌套容器共用一次背景采样。高对比度时关闭光学效果。

这个浏览器小样以及原生软件渲染测试均不能证明手机 GPU 的性能。
